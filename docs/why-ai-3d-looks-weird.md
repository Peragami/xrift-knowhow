# なぜAIの作る3Dモデルは変なのか

2026-11-13、寝室ワールドのベッドを題材に整理した4つの原因と対策。

## 1. 「見ながら」作っていない

人間のモデラーはBlenderで形を見ながら頂点を動かす。LLMは座標の数字を頭の中で計算してコードに書くだけなので、キーボードが机の縁からはみ出して浮く、マットが9cmはみ出す、といったズレが「見るまで」分からない。

**対策**: ローカルレンダリング確認ループ（[render-check-loop.md](render-check-loop.md)）。アップロード前にAI自身が描画してスクリーンショットを見る。加えて座標の自動監査（浮き・はみ出し・めり込みを数値で検出）で、1つの画角では見えないズレを拾う。

## 2. 箱と円柱で組み立てている

基本図形の組み合わせでは、布の垂れ・クッションの沈み・木の反りといった自由曲面が出せない。布団の垂れを薄い箱で付け足せば「板」になり、クッションは「硬い板」に見える（実際に起きた）。

**対策（段階的に）**:

1. 形状部品を増やす: 回転体（LatheGeometry）、チューブ、押し出し、部分トーラスなど
2. 自作メッシュ: 頂点を計算で変形する。布は格子メッシュを重力カーブで垂らし、クッションは中央を膨らませる
3. 本格的な物は `.glb` 化して読み込む（GLTFLoaderは公式対応。BlenderヘッドレスやPythonでのメッシュ生成）

## 3. 「物理」を分かっていない

クッションが柔らかいことは言葉では知っていても、重力でどう潰れるか、布が角でどう折れるかの体感がない。「それっぽい配置」を統計的に出すだけで、物の性質から形を導けない。

**対策**: 失敗から得た原則をルール化して最初から適用する（[verification-rules.md](verification-rules.md) の「柔らかい物の原則」）。必要なら簡易シミュレーションで初期形状を作る。

## 4. AI生成3D全般の破綻

画像と違い3Dは「どの角度から見ても破綻しない」ことが要り、学習データも画像より圧倒的に少ない。脚が5本の椅子、部品の融合、裏側の崩壊などが起きやすい。

**対策**: 生成に丸投げせず、実寸＋部品の組み立て＋目視ループで作るのが現実解。生成を使う場合も「下書き→手直し」に留める。
