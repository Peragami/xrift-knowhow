# 検証ルール

XRiftワールド／アイテム制作で実際に踏んだ失敗から作った確認ルール。

## アップロード前

- 新規ワールドか、既存ワールドの新バージョンかを確認してから上げる。上げる先のIDとバージョンを言い直してから実行する。
- テンプレート同梱の `.xrift/world.json`（他人のワールドID入り）は、新規ワールドの初回アップロード前に必ず削除する。
- アップロードは本人の指示があるときだけ。無断で公開・上書きしない。
- `xrift create item` は対話プロンプトで固まるので `-y`（--no-interactive）必須。

## ローカルでの目視（上げる前）

- [レンダリング確認ループ](render-check-loop.md) で自分の描画を見る。
- 座標監査を併用する: 支持（下に何があるか）・はみ出し・めり込みを、ソースの数値から再計算して照合する。ブラウザ確認の距離目測は過大に出るので、コード座標が正。

## ワールド内確認

- 確認の入室はゲストアカウントで行う（本人のアカウントで入ると、本人の入室と競合して切断されるため）。
- スポーンは家具のない開けた床に置き、スポーン地点そのものから歩行テストする。スポーン埋没は本人の実体験（「埋まって歩けない」）で発覚した。
- ブラウザ側で入力（ポインターロック等）が効かないのはブラウザ側の問題として扱い、ワールドの欠陥と誤判定しない。
- 正面から見えなかった細部（画面の正面など）は「未確認」と明記して残す。
- **本人のワールド内での実体験が最終判定**。ブラウザ確認と食い違ったら本人が正しく、以前の判定をその場で訂正する。

## 柔らかい物の原則（ベッドの失敗から）

- 布の垂れを薄い箱（パネル）で表現しない。チェック柄の板が側面に付いたベッドは「板で囲まれた箱」に見えた。垂れは、布団本体を広げて角の丸みではみ出させるか、垂れ曲線のメッシュで作る。
- クッション類は「大きな板1枚」にしない。厚み（9cm級）＋大きめの角丸＋分割（隙間）で柔らかさが出る。
- 柔らかい物は、接する相手に数mm〜数cm沈ませると自然に「乗っている」ように見える。逆に硬い物の浮き（数mmでも）は目立つので座標で潰す。
- 寝具・布のテクスチャにはノーマルマップを併用すると平坦さが減る。

## 形状の作り方（v19の作り直しで採用）

- 柔らかい物は超楕円体の自作ジオメトリ（パラメトリック、e=3前後）で作る。枕・クッション・パッド・マウスに適用し、「板」感が消えた
- 布の垂れは格子メッシュの高さ関数で作る（縁だけ smoothstep で落とす＋全面に微弱な波）。布団に適用
- 壺・傘・ドーム型は LatheGeometry（回転体）。ランプシェード／土台、天井照明ドーム、植木鉢に適用
- 取っ手類は部分トーラス（arc 280°、両端を本体に埋没）。輪のまま使うと下端が浮いてフックに見える

## スカイボックスと窓（v20の教訓）

- 「窓の外の絵」は壁の内側に貼った平面ポスターだった。本物のスカイボックス（equirect テクスチャ＋半径60の BackSide 球）にするには、壁そのものに開口を開け、ガラス位置に見えないコライダーを張る必要がある。ポスターを消すだけだと壁＋ガラスの反射で真っ白になる
- 月などの天体はドームに描かず、遠方（例: 38m）に別メッシュで置くと視差が自然。スポーンからの見通し線で窓枠内に収まる位置を計算してから置く
- equirect テクスチャは 2048×1024 で生成（星＋天の川）。窓から見える範囲は全体の約40°分なので、星はやや大きく映る。気になる場合は 4096 幅にする
