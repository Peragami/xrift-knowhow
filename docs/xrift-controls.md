# XRift操作リファレンス

2026-11-12の公式調査＋実地確認で確定したもの。公式のユーザー向け操作ページは存在しない。

## 基本（アバター操作）

- 視点: 画面クリックでポインターロック → マウス移動（ドラッグではない）
- 移動: WASD／矢印キー
- ジャンプ: Space／E
- 掴む・置く: G（掴んだままクリックで「使う」）
- ポインターロック解除: Esc
- 人称切替: マウスホイール（一人称⇔三人称。ズームではない）。スマホは2本指ピンチ
- 浮遊（フライ）切替: F。上昇 Space／E、下降 Q（ワールド権限、デフォルトON。無限ジャンプもデフォルトON）
- 落下すると自動リスポーン（手動キーは無し）

## Pキー: フリーカメラ（公式未掲載・実地確定）

- Pで開始／終了。「カメラ操作中（Tabでアバター操作に切替）」と表示される
- WASD移動、Space／E上昇、Q下降、Shift加速
- 視点はポインターロック＋マウス移動（効かない環境ではドラッグでも回らないことがある）
- クリック = 写真撮影、ホイール = ズーム、R長押し = リセット、H = UI非表示、Tab = アバター操作へ
- カメラはアバターの位置・向きから始まるので、まずSで下がってから構図を作る
- 俯瞰にはアバター三人称よりPカメラが向く（三人称はアバターが中央を隠す）

## 確認作業の注意

- ブラウザ自動操作ではポインターロックが開始できないことが多い。その場合は浮遊（F）＋キー移動で位置だけ調整し、向きはスポーンの向きに合わせた構図で確認する。
